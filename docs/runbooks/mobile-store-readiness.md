| Layer | Version (Expo SDK 55) |
|---|---|
| expo | `~55.0.31` |
| react-native | `0.83.10` |

- Android: RN 0.83/Gradle baseline sets `targetSdk 36 / compileSdk 36`,
  meeting Google Play (new apps/updates must target Android 16 / API 36 since 08/31/2026).
- iOS: EAS profiles use `image: latest` (current Xcode 26+ toolchain), meeting
  App Store Connect (uploads require Xcode 26+ / iOS 26 SDK since 04/28/2026).
- Managed/CNG architecture preserved (no committed native dirs; `android/`/`ios/`
  are generated by prebuild at EAS build time).
- New Architecture (Fabric) and edge-to-edge are SDK 55 defaults.
- No secrets/signing/publishing in this repository.

## EAS profiles (`mobile/eas.json`)

| Profile | Use | Android | iOS |
|---|---|---|---|
| `preview` | Internal preview (non-prod) | APK (`buildType: apk`, `distribution: internal`) | Internal device build (`simulator: false`, `image: latest`) |
| `preview-simulator` | iOS Simulator preview (no signing) | - | Simulator |
| `store-preview` | Store preview (no upload) | AAB (`app-bundle`) | Store/TestFlight-ready (`simulator: false`) |
| `production` | Production (prepared, no upload) | AAB | Store/TestFlight-ready |

Current identity remains dev (`com.verah.app.dev` / `verah-dev`); store
identity, Apple Developer/Google Play accounts, certificates, signing and
publishing are **HUMAN gates** - nothing irreversible was created in this issue.

## Reproducible commands

```bash
cd mobile
# engineering (CI-equivalent)
pnpm install --frozen-lockfile
pnpm run check            # tests + typecheck + expo-doctor (20/20 green)

# builds - human account only (EAS login; Apple/Google signing)
pnpm dlx eas-cli@latest build --profile preview --platform android          # internal APK
pnpm dlx eas-cli@latest build --profile preview --platform ios               # internal iOS device
pnpm dlx eas-cli@latest build --profile preview-simulator --platform ios     # iOS Simulator
pnpm dlx eas-cli@latest build --profile store-preview --platform android       # store preview AAB
pnpm dlx eas-cli@latest build --profile store-preview --platform ios           # TestFlight-ready
pnpm dlx eas-cli@latest build --profile production --platform android          # production AAB (no upload)
pnpm dlx eas-cli@latest build --profile production --platform ios              # App Store-ready (no upload)
```

## Final gates (HUMAN)

1. **Expo/EAS**: `eas login` / `EXPO_TOKEN` (founder account).
2. **Google Play Console**: account + payment + App ID/signing; AAB publish/upload
   is human (never automatic).
3. **Apple Developer / App Store Connect**: paid account, store bundle ID,
   certificate + provisioning, TestFlight upload; upload/submission is human.

Nothing in this issue creates mutable store App ID/bundle/package, publishes
or submits builds. Refs #211 #212 #164 #181 #196 #83.
